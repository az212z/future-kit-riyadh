# FUTURE KIT · فيوتشر كيت — الموقع

موقع ثابت (HTML/CSS/JS) لمعرض مطابخ في الرياض، ينشر على GitHub Pages.

## إضافة بيانات التواصل
افتح `assets/site.js` وعدل كائن `CONFIG` في أعلى الملف:
`whatsapp` (مثل 9665XXXXXXXX)، `phone`، `address`، `hours`.
بمجرد إضافة رقم الواتساب تعمل أزرار «أرسل» مباشرة عبر واتساب.

الصور التوضيحية من Unsplash (رخصة Unsplash). ينصح باستبدالها بصور مشاريع حقيقية.
